## Interface improvements

- Added optional larger text and calmer content panels while preserving your chosen theme.
- Organized Settings into General, Appearance, Notifications, and Data & Updates, with search across the groups.
- Added optional navigation favorites and reordering through Customize. All tools remain available; tool search is available with Ctrl+K without a separate navigation search button.
- Fixed the refreshed dialogs to use the selected theme and consistent rectangular controls.
- Added grind-zone favorites, recent zones, gear/region/party filters, drop-name search, and item details with explicit market-version selection.
- Added expanded market charts with linked date inspection, keyboard controls, and clearer loading and unavailable-history states.
- Added remaining-only and nearest-reset options for Weeklies, plus a 60-second Undo for All done that respects resets and subsequent changes.
- Added optional compact Recipe Book results, ingredient details, favorites, and recent searches. The detailed layout remains the default, and planning does not consume inventory.
- The Refreshed interface switch can restore the previous presentation without resetting saved progress.

## Startup and maintenance

- Reduced unnecessary startup asset comparisons using a content manifest and moved the single-instance check earlier to avoid competing startup file writes.
- Added Open immediately when ready while keeping the cinematic introduction available.
- Added control over market-history collection while the app is closed, with background-check status in Settings.
- Expanded automated checks for preferences, market workflows, inventory persistence, weekly resets, UI controls, and installer packaging.
- Added game-data provenance and review checks to support future data maintenance.

## Installation

- Updated the Windows application and native installer to v0.9.63.
- Existing settings, coupon redemption history, weekly progress, inventory, and market history are preserved when updating.
- The installer includes the required .NET runtime. Microsoft Edge WebView2 is checked during installation.
